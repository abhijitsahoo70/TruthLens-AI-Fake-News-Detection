# 🔍 TruthLens AI – Fake News Detection & News Forensics System

> **"Analyze. Detect. Understand. Verify."**

A modern **AI-powered Fake News Detection and News Forensics System** built using **Python, Flask, Machine Learning, Scikit-Learn, SQLite, HTML5, CSS3, JavaScript, Jinja2, and Chart.js**.

TruthLens AI goes beyond simple **REAL / FAKE** classification by analyzing news content using machine learning and linguistic forensics. It generates a credibility score, risk level, clickbait analysis, emotional-language analysis, explainable AI insights, and a detailed news forensics report.

# 🌟 Unique Features

Unlike a basic Fake News Detection project, TruthLens AI provides multiple layers of analysis.

### 🔹 1. Credibility Score

Generates a **0–100 credibility score** using multiple signals such as:

- ML prediction confidence
- Clickbait indicators
- Emotional language
- Excessive capitalization
- Text characteristics
- Article length

### 🔹 2. Clickbait Detector

Detects suspicious headline patterns including:

- Sensational phrases
- Curiosity gaps
- Trigger words
- Excessive punctuation
- Attention-grabbing language

### 🔹 3. Emotional Language Audit

Identifies potentially manipulative language related to:

- Fear
- Anger
- Urgency
- Shock
- Emotional persuasion

### 🔹 4. Explainable AI

Instead of only showing **FAKE** or **REAL**, the system provides an explanation of the prediction using important text features and keywords.

### 🔹 5. News Forensics Report

Each analysis generates a detailed report containing:

- Prediction
- Model confidence
- Credibility score
- Risk level
- Clickbait indicators
- Emotional indicators
- Text statistics
- Explainable AI information

### 🔹 6. User Analysis History

Authenticated users can:

- Save predictions
- View previous analyses
- Search history
- Filter results
- Open individual reports
- Delete individual records
- Delete multiple records
