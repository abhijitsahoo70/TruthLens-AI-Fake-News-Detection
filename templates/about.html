About TruthLens AI

"Analyze. Detect. Understand. Verify."

Project Objective & Scope

TruthLens AI is an advanced, full-stack Machine Learning web application designed to analyze news headlines and articles to detect potential misinformation, clickbait tactics, and emotional manipulation.

Unlike simple binary classifiers that output only a single "REAL" or "FAKE" label, TruthLens AI generates a comprehensive News Forensics Report combining TF-IDF machine learning probability with multi-dimensional heuristic rules (clickbait detection, emotional language intensity, structural text statistics, and explainable feature attributions).

System Architecture & Pipeline

News Input ──► Text Cleaning & Preprocessing ──► TF-IDF Vectorization ──► ML Classifier (Logistic Reg / SVM)
                                                                         │
User Forensics Report ◄── SQLite DB Archiving ◄── Credibility Scoring & Risk Assessment ◄──┘

Technology Stack

Backend & ML

  • Python 3 & Flask Web Framework
  • Scikit-Learn (TF-IDF, Logistic Regression, Naive Bayes, Linear SVM)
  • Pandas & NumPy data manipulation
  • Joblib model serialization

Database & Security

  • SQLite relational database (`database.db`)
  • Werkzeug password hashing (`pbkdf2:sha256`)
  • Flask Session-based authentication
  • Parameterized SQL protection

Frontend & UI

  • HTML5 & Semantic Elements
  • Custom Modern Dark CSS3 Glassmorphism System
  • JavaScript (ES6+) for interactive counters & toggles
  • Chart.js for analytics dashboard

Important Academic Note & Disclaimer

TruthLens AI is an academic demonstration software created for B.Tech CSE / AI-ML projects, portfolio showcases, and viva examinations. It is a machine learning prediction and statistical analysis tool, not an authoritative fact-checking service. Predictions should be interpreted as probabilistic estimates based on trained dataset patterns.
